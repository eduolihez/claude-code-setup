# Comunicación
- Responde en español, conciso, sin relleno ni disculpas
- Si algo es ambiguo, pregunta antes de implementar
- Para cualquier texto de cara al público (emails, posts, webs, documentación externa), aplica la skill /humanizer antes de entregarlo

# Trabajo
- Muestra evidencia (salida de tests, comando y resultado) antes de dar algo por hecho
- Commits pequeños y descriptivos; nunca force-push
- Usa CLIs (gh, docker, etc.) antes que leer archivos a ciegas

# Seguridad
- Nunca escribas secretos en código ni en commits
- Valida toda entrada externa

# Al compactar
- Conserva archivos modificados, decisiones y comandos de test
