name: hackathon-scaffold
description: Prepara un proyecto de hackathon con MVP definido, estructura mínima, README de pitch y checklist de entrega
disable-model-invocation: true
---
Principios: demo primero, sin sobreingeniería. Solo lo que se ve en la demo.

1. Fija el MVP: el problema en una frase y el flujo de la demo (de qué
   entra el usuario a qué resultado ve). Lo que no está en ese flujo queda fuera.
2. Pregunta el stack si no lo conoces. Nunca asumas uno.
3. Propón la estructura mínima de carpetas para ese stack: lo justo para
   arrancar y ejecutar la demo. Muéstrala y espera confirmación antes de crearla.
4. Crea un README orientado al pitch con estas secciones:
   - Problema
   - Solución
   - Demo (pasos para reproducirla)
   - Stack
   - Equipo
5. Entrega el checklist de cierre:
   - [ ] La demo funciona desde un clon limpio
   - [ ] README completo
   - [ ] Licencia incluida
   - [ ] Sin secretos en el código ni en el historial
   - [ ] Formulario de envío completado
